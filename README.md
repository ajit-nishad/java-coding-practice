# Java-Coding-Practice
A structured collection of Java programs covering fundamentals, OOP, collections, Java 8 features, exception handling, multithreading, and advanced Java concepts.

📚 Topics Covered

- 01. Java Basics – Variables, data types, type casting, and input/output
- 02. Operators – Arithmetic, relational, logical, and assignment operators
- 03. Conditional Statements – if, if-else, nested if, and switch
- 04. Loops – for, while, do-while, and nested loops
- 05. Methods – Method declaration, parameters, return types, and method overloading

🛠️ Technologies Used

- Java
- JDK
- IntelliJ IDEA / Eclipse
- Git and GitHub

🎯 Purpose

This repository documents my Java learning journey, strengthens my programming fundamentals, and provides a collection of practice programs for coding and technical interview preparation.

▶️ How to Run

1. Clone this repository.
2. Open the project in your preferred Java IDE.
3. Navigate to the required topic folder.
4. Compile and run the Java program.
